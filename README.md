# Data Structures and Algorithms – Basics

This branch contains implementations and practice problems related to **basic Data Structures and Algorithms (DSA)**.  
It is intended for learning, revision, and strengthening core DSA concepts.

## Topics Covered

- **Arrays**
  - Basic operations
  - Common problems
- **Sorting Algorithms**
  - Bubble Sort
  - Selection Sort
  - Insertion Sort
  - (More can be added)
- **Linked List**
  - Singly Linked List
  - Basic operations (insert, delete, traverse)

## Purpose

- To understand fundamental DSA concepts
- To practice problem-solving skills
- To build a strong foundation for advanced algorithms

## How to Use

1. Navigate to the topic folder
2. Read the code and comments
3. Run the programs and modify them for practice
